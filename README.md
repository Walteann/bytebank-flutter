# 📱 Projeto FIAP – Pos Tech Challenge Fase 03

Aplicação de **gestão financeira** desenvolvida em **Flutter**, voltada para dispositivos móveis (Android e iOS).

---

## 🛠️ Tecnologias Utilizadas

- **Flutter** – Framework para desenvolvimento multiplataforma
- **Dart** – Linguagem de programação
- **Material Design** – Componentes visuais e padrões de UI
- **Firebase**
  - Authentication
  - Firestore
  - Firebase Storage
- **Intl / IMask** – Formatação de valores monetários e datas
- **Gerenciamento de Estado** – setState

---

## ▶️ Como Começar

### 📋 Pré-requisitos

- Flutter SDK instalado
- Dart
- Android Studio ou VS Code
- Emulador Android / iOS ou dispositivo físico

Verifique a instalação com:
```bash
flutter doctor
```
---

## ▶️ Executando o Projeto

Clone o repositório:
```bash
git clone https://github.com/Walteann/bytebank-flutter.git
```
Acesse a pasta do projeto:
```bash
cd bytebank-flutter
```
Instale as dependências:
```bash
flutter pub get
```
Execute a aplicação:
```bash
flutter run
```

## 🎯 Objetivo do Projeto

Este projeto faz parte do Pos Tech Challenge – FIAP, Fase 03, e tem como objetivo aplicar conceitos de desenvolvimento mobile, organização de código e boas práticas no desenvolvimento de uma aplicação de gestão financeira.
